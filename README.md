# Weather App 🌦️

A responsive Weather App built using React.js, Vite, Material UI, and OpenWeather API. Users can search any city to get real-time weather information including temperature, humidity, minimum and maximum temperature, feels-like temperature, and weather description. The application also displays dynamic weather images and icons based on current weather conditions with a modern glassmorphism user interface.

## Features
- Search weather by city
- Real-time weather data
- Dynamic weather images
- Dynamic weather icons
- Responsive design
- Material UI components
- Glassmorphism UI

## Technologies Used
- React.js
- Vite
- Material UI
- CSS3
- OpenWeather API
- Fetch API
